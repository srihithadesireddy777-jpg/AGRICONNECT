🌱 AgriConnect

Connecting Farmers, Customers & Opportunities

AgriConnect is a full-stack agricultural marketplace platform designed to bring farmers and customers together through a simple, accessible digital experience.

The platform helps farmers showcase their agricultural products, connect with customers, share knowledge, and participate in an agricultural community.

---

🚀 Key Features

- Farmer Verification: Farmers can submit applications for verification.
- Product Marketplace: Farmers can list products, while customers can explore and purchase them.
- Community Forum: Users can share crop-related information, images, and discussions.
- Crop Care Guidance: Access useful information about crop diseases, pesticides, and farming practices.
- Messaging System: Enables communication between farmers and customers.
- Admin Dashboard: Administrators can review and approve or reject farmer applications.
- Product Categories: Supports organic and conventional agricultural products.

👥 User Roles

Role| Responsibilities
Farmer| Apply for verification and manage products
Customer| Browse products and interact with farmers
Admin| Manage farmer verification and platform activities

🛠️ Technology Stack

- Frontend: React.js
- Build Tool: Vite
- Backend: Node.js and Express.js
- Database: MySQL

🔗 API Endpoints

Endpoint| Function
"/api/auth/register"| User registration
"/api/auth/login"| User login
"/api/farmers/apply"| Farmer verification
"/api/admin/farmers/:id"| Approve or reject farmers
"/api/products"| View or add products
"/api/community/posts"| Community posts
"/api/messages"| Messaging

🎯 Project Objective

To create a digital agricultural ecosystem that simplifies connections between farmers and customers, encourages knowledge sharing, and makes agricultural products more accessible.

🌍 Vision

Empowering farmers through technology and building a smarter, more connected agricultural community.
